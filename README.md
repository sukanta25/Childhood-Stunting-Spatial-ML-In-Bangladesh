# Childhood-Stunting-Spatial-ML-In-Bangladesh

Source code for the M.Sc. thesis: **Childhood Stunting in Bangladesh using Spatial Machine Learning and Explainable AI**.

## Contents
- Feature selection (Gradient Boosting, RFECV, Sequential Forward & Backward Selection)
- Resampling ( with SMOTE & SMOTETomek)
- SHAP and GeoShapley explainability analysis
- Moran's I, LISA, GWR, MGWR

## Data
Raw BDHS 2022 data is not included due to DHS data-sharing restrictions. Data can be requested from [DHS Program](https://dhsprogram.com).
